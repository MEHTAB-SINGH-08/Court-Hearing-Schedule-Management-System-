
# JUSTICE
## Court Hearing Schedule Management System

### Project Overview
JUSTICE is a frontend-based Court Hearing Schedule Management System developed as an academic group project. It provides a simple interface for managing and viewing court cases, hearing schedules, and calendar events.

### Project Objectives
- Provide an organized dashboard for court information.
- Display and filter hearing records.
- View case details.
- Manage hearing schedules through a calendar.
- Demonstrate frontend web development concepts.

### Key Features
- Login interface
- Dashboard with summary statistics
- Hearing management with search and status filters
- Add Hearing form
- Case management with search and status filters
- Individual case details page
- Interactive hearing calendar
- About Project page

### Technologies Used
- HTML5
- CSS3
- JavaScript
