About JUSTICE

Court Hearing Schedule Management System

Project Overview

Created by students of Lovely Professional University. JUSTICE is a frontend-based Court Hearing Schedule Management System designed to provide an organized interface for viewing and managing court hearing schedules and case information.

Project Objectives

  • Provide an organized view of court hearings.
  • Display case information and hearing history.
  • Allow users to search and filter hearing records.
  • Provide a calendar for viewing scheduled hearings.
  • Create a simple and professional administrative interface.

Key Features

Dashboard

Overview of hearings, schedules and activities.

Hearing Management

Search, filter and view hearing records.

Case Information

View case details and hearing history.

Hearing Calendar

Navigate dates and view scheduled hearings.

Technologies Used

HTML5 CSS3 JavaScript
